# Cakna — Flutter app

Android + iOS client for Cakna. See the [root README](../README.md) for the project as a whole and
[RELEASE.md](RELEASE.md) for store packaging.

Unlike the web SPA, the app is **offline-first**: the Quran text, page map, word-by-word glosses and
tajweed all ship as bundled assets (`assets/data/`, generated by `tool/bundle_assets.sh`) and are
read from a local SQLite database. The network is needed only for prayer times, audio streaming and
— when signed in — cloud sync.

## Dev

    flutter pub get
    flutter run

    dart analyze                 # lints per analysis_options.yaml
    flutter test

## Layout

    lib/data/        SQLite repos, models, reciter table, word timings
    lib/screens/     one file per screen; app_shell.dart owns the 5 tabs
    lib/state/       app state, audio, auth, sync, Ma'thurat
    lib/services/    prayer times, notifications, tafsir, home-screen widget
    lib/widgets/     shared UI (mushaf page, verse sheet, mini player)
    lib/utils/       hijri, JAKIM zones, prayer maths
    tool/            asset bundling

## Audio

`lib/data/reciters.dart` holds 12 reciters with CDN-verified sources. Ten stream from
cdn.islamic.network at a **per-edition bitrate** — several editions are not published at 128 kbps
and return 403 if requested there. Two exist only on everyayah.com, which addresses files as
zero-padded `{surah}{ayah}` rather than by global ayah number. The same bitrate table is mirrored in
`web/src/lib/quran/meta.ts`; keep the two in step.

## Sync

Signing in uses the same Rust API as the web (`/api/auth/*`, `/api/sync`). Two current gaps:

- **Ma'thurat progress is device-local.** `lib/state/mathurat_state.dart` persists to a
  `SharedPreferences` key (`mathurat_progress`), not the `mathurat` sync key — so it has no cloud
  backup and does not survive a reinstall.
- **QCXIS SSO is web-only.** The app offers email/password. Adding SSO needs `flutter_web_auth_2`,
  a second registered redirect URI, and a token-handback design.

## Al-Ma'thurat data

`assets/data/mathurat.json` is the 28-item sample-extracted set. The canonical dataset is the
46-item one in `web/src/lib/data/mathurat-master.ts` — see [DECISIONS.md](../DECISIONS.md). Until
that migration lands, **web and app show different wirid content**.
